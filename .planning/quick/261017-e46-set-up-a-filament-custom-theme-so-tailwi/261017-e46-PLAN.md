## Verified facts (live, planning time)

- Filament `^5.10`. `vendor/filament/filament/src/Commands/MakeThemeCommand.php` (`make:filament-theme`) does four things: (1) UNCONDITIONALLY runs `npm install tailwindcss@latest @tailwindcss/vite --save-dev`, (2) writes `resources/css/filament/{panelId}/theme.css` from `vendor/filament/filament/stubs/ThemeCss.stub`, (3) regex-inserts the path into vite.config.js `input`, (4) regex-inserts `->viteTheme(...)` after `->id(...)` in the panel provider, then interactively prompts to run `npm run build`.
- Step (1) would rewrite the exact pins `"tailwindcss": "4.3.3"` / `"@tailwindcss/vite": "4.3.3"` in package.json + package-lock.json to `@latest` with caret ranges. The project pins exact versions and builds offline (CAL-01), so DO NOT run the artisan command; hand-author the identical output instead (steps 2–4 below reproduce it exactly).
- Stub content (ThemeCss.stub): an `@import` of the vendor Filament theme CSS, then `@source '../../../../app/Filament/{classDirectory}**/*';` and `@source '../../../../resources/views/filament/{viewDirectory}**/*';`. For this panel the page directory is `app/Filament/Pages`, so `classDirectory` and `viewDirectory` resolve to empty strings.
- `vendor/filament/filament/resources/css/theme.css` is `@import 'tailwindcss' source(none);` + `@import './index.css';` — it brings its own Tailwind import, so the admin theme must NOT import tailwindcss again and must NOT import resources/css/app.css (that file strips Tailwind's palette with `--color-*: initial`, which would break Filament's gray/amber colours).
- `HasTheme::getTheme()` resolves the theme via `app(Vite::class)(...)`; tests/Pest.php calls `$this->withoutVite()` for all Feature tests, so feature tests do not need a built manifest.
- System health view currently wraps sections in a div with an inline style attribute plus a one-line Blade comment explaining the missing theme; the inner `grid gap-1 text-sm` and `text-gray-500 dark:text-gray-400` classes are already Tailwind and will start working too.
- The public bundle resources/css/app.css has `@source '../views/**/*.blade.php'` (which also scans filament views). Leave it unchanged — out of scope. Because of that, the `.gap-6` proof MUST read the admin theme's own built file via the Vite manifest, not grep all of public/build.
</context>
