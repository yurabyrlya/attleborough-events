<objective>
Turn 02-01's single path into a dependable approval contract: a single `DraftPublishability` rule decides what can be published (and why not), `ApproveDraft` enforces it on the locked row, `DraftWriter::update()` lets the admin fix a draft, `CategoryAssigner` gives the chain's two ends (preferred category, else flagged Other), and an arch test makes `PublishEvent` reachable only from Publishing actions. Recurring series are proven to publish once with correct DST instants.

Purpose: REV-02 (contract) and REV-11; the bulk-skip keys the queue (02-13) needs; D-06, D-10, D-21 rules.
Output: QualityBand enum, review config, CategoryAssigner + CategoryDecision, DraftPublishability, ApproveDraft/DraftWriter changes, the draft factory, and four test files.
</objective>

## Phase Goal

"…one review queue that is the only path to publication." This plan makes "only path" enforceable and the refusal reasons precise.

## Wave-2 file ownership (parallel with 02-04 and 02-05)

02-04 owns events columns, `PublishableEventData`, `EventForm`, `Event`, public read DTOs/views, `CreateEventTest`. 02-05 owns routes, the submission controller/request/views, `DraftData`, layout, `submit.js`, `vite.config.js`, `tests/Pest.php`. This plan owns its `files_modified` only.

## Interfaces this plan creates

- `DraftPublishability::blockers(EventDraft $draft): list<string>` (single approve, Approve button, A key, ApproveDraft); `bulkBlockerKeys(EventDraft $draft): list<string>`; `static skipMessage(string $key, int $count): string`.
- `DraftWriter::update(EventDraft $draft, DraftData $data): EventDraft` (admin-only callers; refuses non-pending drafts).
- `CategoryAssigner::assign(?int $preferredCategoryId, EventOrigin $origin, list<string> $sourceValues, string $title): CategoryDecision` and `static normalise(string $value): string` (NFC, mb_strtolower, collapsed whitespace; used by 02-07/02-11 for equality).
- `QualityBand::fromScore(int $score): self`; `config/review.php` keys `quality.weights.*`, `quality.bands.*`, `retention_days.*`, `submission.*`, `venue_similarity_threshold`.
