<objective>
Lay the thinnest real path of the phase: the admin's New event form now writes a `manual` draft and approves it at once through a new `App\Publishing\Actions\ApproveDraft`, which wraps Phase 1's `PublishEvent` in one transaction (D-07). This creates the `event_drafts` table and model, the draft DTO and writer, and the approval action that every later Phase 2 plan builds on.

Purpose: REV-02 (one-transaction approval, approver/time recorded, manual entry through the review path). The approval contract (blockers, DST series, double approve, arch test) is plan 02-03; contact columns on events are 02-04; reject/reopen/purge is 02-06.
Output: three enums, two exceptions, the `event_drafts` migration, `EventDraft`, `DraftData`, `DraftWriter`, `ReferenceCode`, `ApproveDraft`, `PublishableEventData::fromDraft()`, the rerouted `CreateEvent`, and one tracer test.
</objective>

## Phase Goal

ROADMAP Phase 2: "…the admin can triage every incoming draft quickly through one review queue that is the only path to publication." After this plan every new event has an approved draft behind it.

## Phase plan map (after the 2026-10-17 split)

W1: 02-01 manual-entry tracer, 02-02 source research · W2: 02-03 approval contract, 02-04 organiser contact choice, 02-05 submission form · W3: 02-06 reject/reopen/purge, 02-07 keyword rules + Rules screen, 02-08 quality + venue matching, 02-09 spam defence, 02-10 rate limit + rules exception · W4: 02-11 mappings/geofence/seeder, 02-12 review queue + detail + search · W5: 02-13 tabs/filters/bulk, 02-14 edit-and-approve · W6: 02-15 Approve & next · W7: 02-16 browser UAT.

## Interfaces this plan creates (later plans extend, never re-create)

- `DraftWriter::create(DraftData $data): EventDraft`, with one private `derive(EventDraft $draft, DraftData $data): void` called on every write. - `PublishableEventData::fromDraft(EventDraft $draft): self`. 02-04 adds `organiserWebsite` / `contactPublic`.
- `ReviewStatus` (state machine), `DraftKind`, `ExtractionMethod`, `InvalidReviewTransition`, `DraftNotPublishable`.
