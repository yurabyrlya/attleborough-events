1. `App\Review\ReviewQueue` (injectable, PublicOccurrenceQuery style). One private constant list of sort expressions: `(start_date is null)`, `start_date`, `(start_time is not null)`, `start_time`, `created_at`, `id`, all ascending. `applyOrder()` orders by them (equivalent to "start_date nulls last, start_time nulls first"); `query()` = pending drafts ordered. `next()` / `previous()` use a row-value keyset over the same expressions with nulls replaced only inside their flag group: `((start_date is null), coalesce(start_date, '9999-12-31'), (start_time is not null), coalesce(start_time, '00:00'), created_at, id) > (?, ?, ?, ?, ?, ?)` (and `<` with descending order for previous), with bound values computed from the current draft the same way.
