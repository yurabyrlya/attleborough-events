## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → PublishEvent | Phase 2 approval and future jobs call the action outside the Filament panel gate; the User passed in is not proven to be the admin |

| stored RRULE → ManualRecurrence | rules written by importers or manual SQL are parsed back |
