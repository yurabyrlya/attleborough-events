<objective>
Close the two new warnings from the Phase 1 re-review (01-REVIEW.md) before sign-off.

- **WR-10:** the edit page and UpdatePublishedEvent judge whether a stored RRULE is editable by its shape only (tryFromRrule). A rule whose BYDAY disagrees with the start date opens as editable. Saving any field then rewrites the schedule to the start date's weekday, and OccurrenceGenerator::sync deletes the future occurrences of the old schedule, including admin cancellations and the UIDs residents already imported.
- **WR-11:** EventOccurrence still lets `status` be mass-assigned.

**WR-10 decision** (owner-specified): a rule counts as representable only if parse → rebuild via ManualRecurrence for the event's own start date and all_day gives back exactly the stored rule. Every other rule takes the read-only / refused path that 01-13 built:

- the EditEvent form (warning, disabled form, no Save, Halt on a forced save);
- the domain refusal in UpdatePublishedEvent on the locked row.

**Agent's discretion:**

- The pure round-trip check lives in ManualRecurrence. It is unit-testable against the existing "emitted rules" dataset, so app-written rules are proven to stay editable.
- The Event → start-date adapter lives in PublishableEventData, which already maps Event ↔ form state.
- UpdatePublishedEvent::canEdit, PublishableEventData::fromEvent and the events table label all use that one adapter, so the page, the domain and the list cannot disagree.
- Leaving the label on the old shape-only parse would keep showing "Weekly on Friday" for a Monday rule (the review's fix note). Aligning it is one line in a file that Task 2 owns.

Purpose: ADM-03 (edits go through the single choke point and admin-set occurrence status survives regeneration), REC-01 (regeneration preserves admin-set status), and EVT-06 (stable `.ics` UIDs) must hold for rules that importers or SQL may store.

MVP note: the Phase 1 ROADMAP Goal is not written as a user story (flagged in 01-VERIFICATION.md). This gap plan does not invent one.

Output: the round-trip check and its wiring, WR-10 repro tests, EventOccurrence fillable fix plus its test, the table label alignment, and an accurate AGENTS.md "Writes" bullet.
</objective>
