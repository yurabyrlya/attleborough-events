## Flagged Assumptions

- **URL scheme `/events/{slug}` (orchestrator outline) instead of RESEARCH Pattern 6's `/events/{id}/{slug}`.** Pure slugs read better in WhatsApp/Facebook shares. The cost is a UNIQUE slug and an `event_slugs` history table, which Task 2 adds. RESEARCH's "no slug_history table" shortcut therefore does not apply. Slugs follow the title automatically, and there is no admin slug field (discretion, keeps the single write path).
- **UID differs for one-off vs series.** RESEARCH gives `{event_id}-{recurrence_key}@…` for every occurrence. For a one-off event that would change when the admin moves its date (01-01 regenerates the key from start_date), so one-off events use `{event_id}@…` and a moved one-off updates the existing calendar entry on re-import. Turning a one-off into a series (or back) changes the shape, so a resident who already imported that date gets a second entry on re-import and must delete the old one by hand (the old UID is never cancelled). Those are different events in calendar terms and such conversions are rare, so this is accepted rather than keying one-offs by start_date, which would break the "moved one-off updates in place" property above. Weekday changes to a series create new occurrence keys and therefore new UIDs (same reason).
- **The .ics DTEND for an event with no end time** is `expires_at` (start + 3h, the site's own expiry rule), and DESCRIPTION (and 01-10's Google details) say "Finish time not given." so the guess is not shown as fact.
- **SEQUENCE** is derived from last-modified seconds since 2026-01-01 UTC. It is monotonic and fits a 32-bit integer for decades. The daily upsert touches updated_at, so SEQUENCE may rise without visible change, which is harmless.
- **Discovered-event excerpt branch of EVT-01** ("excerpt up to 200 characters plus Read more at {source}") applies to `origin = discovered`, which cannot exist until Phase 3 (Phase 3 success criterion 5 owns it). Phase 1 renders the full description for manual events. Submissions (Phase 2) also get the full description per EVT-01.
